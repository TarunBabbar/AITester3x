# Sample Python OOP Examples

Small, self-contained Python OOP demos — classes, inheritance,
polymorphism, encapsulation, abstraction, and dunder methods.

## Files

| File | Demonstrates |
|------|--------------|
| `car.py` | Class attributes, methods, object state |
| `inheritance.py` | Inheritance + polymorphism |
| `encapsulation.py` | Private members, properties, error handling |
| `abstraction.py` | ABCs and abstract methods |
| `class_static_methods.py` | Classmethods, staticmethods, `__repr__`, `__eq__` |
| `test_samples.py` | pytest tests for the above |

## Run

```bash
python car.py
python inheritance.py
python encapsulation.py
python abstraction.py
python class_static_methods.py
```

## Test

```bash
pip install pytest
pytest test_samples.py -v
```
